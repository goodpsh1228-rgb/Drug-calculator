# 브랜드 자산

**이름**: 영문 `Veterinary Dose Calculator`(메인) / 한글 `수의학 약물 계산기`(보조) / 홈 화면 이름 `약물 계산기`

**서체**: 영문 Newsreader (Veterinary는 Italic 500, Dose Calculator는 SemiBold 600), 한글 나눔명조 Bold.
두 서체 모두 SIL Open Font License이며, 로고 이미지에는 글자가 이미 그려져 있어 서체 파일이 필요 없습니다.
화면 UI의 입력창과 결과 숫자는 Pretendard / JetBrains Mono를 씁니다.

**색**

| 용도 | 밝은 배경 | 어두운 배경 |
|---|---|---|
| 앰플 윤곽선 | `#14181C` | `#E8ECEF` |
| 액체(포인트) | `#0891A1` | `#35D0E0` |
| 앱 아이콘 바탕 | `#0F1317` | `#0F1317` |
